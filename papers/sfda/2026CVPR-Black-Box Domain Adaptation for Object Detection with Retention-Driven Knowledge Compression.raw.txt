Abstract
Black-Box Domain Adaptation (BBDA) is a highly practical
yet challenging strategy that enables the deployment of pre-
trained detectors to new unlabeled target domains without
accessing source data or models. Compared to previous do-
main adaptation studies, BBDA not only provides stronger
data privacy protection but also offers greater portability.
Despite growing interest, existing BBDA strategies remain
difficult to apply directly to object detection, as most prior
works focus on classification and segmentation tasks that
do not involve bounding box localization and rely on differ-
ent learning mechanisms. In this paper, inspired by lifelong
learning, we propose Retention-Driven Knowledge Com-
pression (RDKC), which applies a brain-inspired learning
process to BBDA for object detection. Specifically, RDKC
consists of two key components: Memory Retention (MR)
and Scene Compression (SC). MR is designed specifically
for object detection under the BBDA setting, where it per-
forms memorized contrastive learning on partitioned re-
gions to better utilize informative cues from reliable areas
while filtering out potential noise from noise prediction la-
bels. SC introduces a contrastive mechanism between near
and far-view regions, which enables the model to better
learn from far-view regions under the guidance of near-
view cues. Experimental results demonstrate that under the
BBDA setting, RDKC outperforms previous SOTA methods
across all evaluated benchmarks, achieving superior per-
formance improvements.
1. Introduction
To mitigate domain shift in deep neural network training
[17], traditional unsupervised domain adaptation (UDA)
methods [20, 24, 39, 40, 62] adapt models trained on
fully labeled source domains to unlabeled target domains,
thereby reducing the burden of data collection and annota-

tion. However, in privacy-sensitive scenarios such as per-
sonal medical records, access to source data is often re-
stricted by privacy-preserving policies, limiting the practi-
cal deployment of UDA techniques. To address this lim-
itation, source-free domain adaptation (SFDA) methods
[16, 21, 31, 50, 55] have recently emerged, assuming ac-
cess only to unlabeled target data and a pre-trained source
model during adaptation. While SFDA reduces the risk of
privacy breaches by using the model instead of raw source
data, prior work [33] has shown that certain generative
techniques [11, 13] can potentially reconstruct source data
from the source model. Compared to other UDA settings,
black-box domain adaptation (BBDA) offers stronger pri-
vacy guarantees and greater deployment flexibility. By re-
lying solely on unlabeled target data and a black-box pre-
dictor trained on the source domain, e.g., a cloud API ser-
vice [33], BBDA avoids privacy and security risks associ-
ated with source data or model exposure. As illustrated in
Figure 1, the BBDA process and its advantages are detailed.
Recent visual studies [32–34, 52–54, 57, 59] on BBDA
have primarily focused on image classification tasks.
BBDA for object detection is notably more challenging
than for classification tasks. While classification involves a
global-to-category mapping, object detection requires joint
learning of local features for both bounding box localization
and category prediction. However, existing BBDA learning
strategies lack optimization for localization, which limits
their applicability to object detection tasks. Moreover, these
methods typically rely on adaptive label smoothing [33] to
store global features of the entire image and perform cumu-
lative predictions, which is inconsistent with the dynamic
and region-specific prediction mechanism of object detec-
tion.

Driven Knowledge Compression (RDKC), which provides
a versatile solution for black-box domain adaptive object
detection. RDKC is the first to address the BBDA task
through lifelong learning in biological behavioral science

Human memory inherently balances three key processes to
enable lifelong knowledge acquisition: 1) active forgetting,
which identifies low-value information and reallocates cog-
nitive resources for new learning; 2) selective stabilization,
which prioritizes valuable information; and 3) collaborative
integration across specialized modules, in which the out-
puts from high-robustness and low-robustness systems are
jointly integrated to support cross-context learning. Specif-
ically, RDKC comprises two main components: Memory
Retention (MR) and Scene Compression (SC). Motivated by
the observation of local image regions and the limitations of
prior approaches, MR is a specific design for category op-
timization in object detection under BBDA settings, which
emulates the active forgetting mechanism by reallocating
contrastive learning across specific regions during train-
ing. This allows the model to suppress potential noise from
noise prediction labels while making better use of informa-
tive cues from high-reliable regions. To enhance the fine-
grained perception of bounding boxes for targets, we pro-
pose a contrastive module SC, which emulates the selective
stabilization mechanism. In SC, we introduce a scene dis-
crimination that adaptively compresses weights, enabling
the model to learn far-view representations guided by highly
reliable near-view cues. By conducting contrastive analysis
of feature disparities between near-view and far-view ob-
ject regions, the SC module enhances the model’s localiza-
tion capability. Meanwhile, we introduce a teacher-student
model [45] as the collaborative mechanism across special-
ized modules, integrating it into the contrastive learning
process to prevent catastrophic forgetting. To better illus-
trate the applicability of our method to BBDA, we present
a detailed comparison in Figure 2.
Our contributions can be summarized as follows:
• We identify critical limitations in existing domain adapta-
tion methods and tackle them by proposing a novel frame-
work, named RDKC, inspired by biological behavioral
science, which provides a versatile solution for black-box
domain adaptive object detection.
• RDKC consists of Memory Retention (MR) and Scene
Compression (SC). MR is specifically designed for ob-
ject detection under BBDA to suppress noise from
noise prediction labels and exploit informative cues from
high-confidence areas. SC employs differential con-
trastive analysis between near- and far-view regions to
enhance the fine-grained perception of bounding boxes.
• To evaluate the effectiveness of RDKC, we conducted
extensive experiments and achieved SOTA performance
across all benchmarks. Cross-method experiments fur-
ther verified its versatility, while ablation studies revealed
the contributions of individual modules and provided an
in-depth analysis of their intrinsic correlations.
2. Related Works
2.1. UDA for Object Detection
Unsupervised domain adaptation (UDA) aims to transfer
knowledge from a labeled source domain to a related but
unlabeled target domain. It has attracted growing attention
across various deep learning tasks, such as image classifi-
cation [20, 39, 51], semantic segmentation [18, 19, 28, 62],
time series forecasting [1, 24, 35, 41], and object detection
[3, 26, 40, 42, 56]. In object detection, UDA is often for-
mulated as unsupervised domain adaptive object detection
(UDAOD). Despite previous works have made certain con-
tributions, UDAOD requires access to both source and tar-
get data during training, which is impractical under privacy-
preserving constraints that restrict the use of source data.

2.2. SFDA for Object Detection
In comparison to UDA, source-free domain adaptation
(SFDA) offers enhanced privacy protection by eliminat-
ing the need to access any source data. Recent advances
in SFDA have led to the development of various meth-
ods [16, 21, 55] that require only unlabeled target data
and a pre-trained source domain model during training. In
object detection, SFDA is typically formulated as source-
free domain adaptive object detection (SFOD). Existing
SFOD methods mainly follow three technical paradigms:
pseudo-label refinement [4, 30, 61], knowledge distillation
[9, 29, 36], and domain alignment [5, 47, 55]. While SFOD
has partially addressed privacy concerns, recent studies [33]
reveal that exposing details of source-free model training
still pose significant risks, primarily due to reverse gener-
ation techniques such as those proposed in [11, 13]. De-
tailed analyses of related works in UDAOD and SFOD are
presented in Supplementary Material A.
2.3. BBDA for Object Detection
Recent advancements in generative adversarial networks
(GANs) have significantly increased the sophistication of
GAN-based white-box attacks, which now require access
to source models to reconstruct original training data [33].
In contrast, BBDA eliminates the need for source data
or model access, offering stronger privacy protection than
other domain adaptation settings and reducing the risk of
data breaches. Early work such as LNL-KL [57] explores
noisy label learning through soft label utilization. More re-
cent approaches, like DINE [33], adopt a two-stage pro-
cess: first distilling knowledge to align source and target
classes, then fine-tuning the distilled model to fit the tar-
get distribution by leveraging reliable knowledge to clus-
ter uncertain samples. Building on self-distillation, subse-
quent methods [52, 54] further divide the target domain into
high- and low-reliability subdomains to reduce distribution
gaps. BiMem [58] introduces information discrimination
to prioritize informative samples over irrelevant ones dur-
ing training. RFC [59] extends earlier works [33, 54] by
incorporating neighborhood clustering to mitigate the for-
getting of minority classes. Additionally, AEM [53] pio-
neers the use of multi-modal models as external prompts in
BBDA, leveraging their rich semantic representations to en-
hance target domain feature alignment. However, existing
studies remain primarily focused on classification tasks. In
black-box domain adaptive object detection (BBOD), only
BiMem has been proposed, which is derived from the clas-
sification method DINE. While classification centers on a
global-to-category mapping, object detection requires joint
learning of local features for both bounding box localiza-
tion and category prediction. Current BBDA methods still
lack well-established solutions for object detection tasks.
To clarify these limitations, we provide a detailed analysis
in Figure 2.

3.2. Lifelong Learning-inspired RDKC Framework
In lifelong learning [27, 38], human memory functions
as a dynamic adaptive system that continuously balances
three interdependent processes to sustain lifelong knowl-
edge acquisition: (1) active forgetting, which selectively
identifies and removes low-value or outdated information
through molecular and neural mechanisms, thereby reallo-
cating cognitive resources to facilitate new learning; (2) se-
lective stabilization, which preserves high-value informa-
tion by strengthening the associated neural pathways, en-
suring the retention of critical knowledge and frequently
used skills; and (3) collaborative integration across special-
ized modules, where distinct memory subsystems operate as
804
parallel learners, and the outputs from high-robustness and
low-robustness systems are synergistically integrated to en-
hance cross-context generalization and adaptive reasoning.
Although the mean-teacher framework [45] facilitates
the distillation of target-domain knowledge into the model
in BBDA, it remains limited in its ability to learn target
features without guidance from source knowledge. To ad-
dress this limitation, inspired by lifelong learning, RDKC
is developed based on two key principles: active forget-
ting and stability preservation. It introduces Memory Reten-
tion and Scene Compression to actively regulate the balance
between memory preservation and forgetting. Meanwhile,
RDKC integrates the multi-model collaborative optimiza-
tion from the mean-teacher framework, where the teacher
model guides the student model as the foundation for dis-
tributional compatibility. This integration within the de-
tection frameworks enhances cross-context generalization
and adaptive reasoning, which further enhances target fea-
ture discrimination. The RDKC training process is shown
in Figure 3. Detailed analyses of the relationship between
lifelong learning and RDKC is presented in Supplementary
Material B.

3.4. Scene Compression

is a positive correlation between the feature distance of

memory optimization loss LMR to prioritize the learning
of high-confidence class-dominated bounding boxes over
background regions. This enables the student model to
learn far-view representations under the guidance of near-
view visual cues. To realize the intended effect of SC, we
combine the memory optimization loss LMR with the scene
compression weight Wi,j, which can be formulated as:

4. Experiments
Datasets. The evaluation is conducted on six widely
used domain adaptive object detection benchmarks, cover-
ing four domain shift scenarios: Cityscapes [6] → Foggy-
Cityscapes [15], Sim10k [25] → Cityscapes [6], KITTI [12]
→ Cityscapes [6], and Pascal-VOC [10] → Watercolor
[22]. Specific dataset details are presented in Supplemen-
tary Material C.
Implementation Details. Our implementation is built upon
PyTorch with all experiments conducted on an NVIDIA
GeForce RTX4090 GPU. To make fair comparisons, fol-
lowing previous methods [47, 55], we adopt Faster R-CNN
[3] as our default object detector, employing a ResNet-
50 [17] backbone pre-trained on ImageNet [7]. The opti-
mizer is stochastic gradient descent (SGD) configured with
a learning rate α of 0.001, momentum of 0.9, and weight
decay of 0.0001. The Exponential Moving Average (EMA)
rate β for updating the teacher model is set to 0.8. The
knowledge distillation stage is trained for 5 epochs, fol-
lowed by 10 epochs in the black-box training stage. More
details are presented in Supplementary Material D.
Comparison Methods. We evaluate the performance
by comparing RDKC with several related methods across
UDA, SFDA, and BBDA settings. For UDA, we conduct
comparisons with DA-Faster [3], MeGA-CDA [46], Unbi-
asedDA [8], TIA [60], and PT [2]. For SFDA, we compare
with MT [45], SFOD [30], A2
SFOD [5], LPU [4], IRG
[47], PTVM [9], and LPLD [55]. For BBDA, we com-
pare our method with previous SOTA approaches, DINE
[33], BiMem [58], and SEAL [52]. Note that BiMem does
not provide a complete solution for object detection, while
DINE and SEAL are re-implemented by us for fair com-
parison. For a more comprehensive comparison, we adapt
the previous SFDA methods IRG and LPLD to the BBDA
setting under the same experimental conditions.
Qualitative and Quantitative Results. As shown in Tables
1, 2, and 3, the results demonstrate that RDKC significantly
outperforms previous SOTA methods across all four adapta-
tion scenarios. Compared with the previous BBDA method
DINE, RDKC achieves a +4.2 improvement in mean Av-
erage Precision (mAP) on Cityscapes → Foggy-Cityscapes
and +8.1 on Pascal-VOC → Watercolor. Additionally, the
average precision (AP) for the car category improves by
+11.2 on Sim10K → Cityscapes and by +10.6 on KITTI
→ Cityscapes. Moreover, we construct cross-method ex-
periments to validate that MR is specifically designed for
the BBDA setting, effectively addressing the performance
limitations of prior SFDA methods under this challenging
setup. When integrated with previous SFDA methods IRG
and LPLD, MR also exhibits remarkable effectiveness.
In Figure 4, we conduct qualitative experiments to com-
pare our method RDKC with the baseline model, the
source-only trained model, and the LPLD and SEAL meth-
ods. These results indicate that RDKC yields higher-quality
predictions, outperforming the compared methods in both
localization accuracy and semantic confidence. Supple-
mentary Material E presents additional quantitative exper-
iments on more datasets, resource consumption compar-
isons, and qualitative studies demonstrating the architec-
tural versatility of our framework.

Ablation Study. As shown in Tables 1, 2, and 3, we con-
duct quantitative ablations under different scenarios, where
w/o SC denotes RDKC without SC, implemented by fix-
ing Wi,j to 1. The results demonstrate that MR is a loss
function specifically designed for BBDA and plays an es-
sential role in such scenarios. When integrated with exist-
ing SFDA methods, MR effectively mitigates performance
degradation caused by the static nature of noisy target la-
bels. When MR and SC are combined, SC guides the
memory optimization loss LMR to focus on learning class-
dominant bounding boxes with high confidence rather than
background regions. In Figure 4, we observe that without
SC, the model exhibits limited scene understanding: high-
confidence class-dominant regions (e.g., the close-up tar-
get in the second row) show overlapping annotations, while
low-confidence far-view objects are often missed. When
our method is fully applied, RDKC continuously refines
the learning of near-view regions while suppressing inter-
ference from distant areas, enabling the student model to
learn far-view representations guided by near-view visual
cues. As shown in Figure 4, even fine-grained objects in
distant scenes can be accurately perceived.
5. Conclusion
In this work, we observe some weaknesses in existing
BBDA methods and address them by proposing a novel
method, RDKC. RDKC is a versatile solution for black-
box domain adaptive object detection, consisting of two key
components: Memory Retention (MR) and Scene Compres-
sion (SC). MR is specifically designed to optimize category-
level predictions in BBDA scenarios, mitigating the perfor-
mance degradation observed in previous methods lacking
access to source models. SC is a contrastive module that
enhances the fine-grained perception of bounding boxes.
Experimental results show that RDKC consistently outper-
forms previous SOTA methods across all benchmarks.
