# BCI Final Paper

Topic:

```text
FAD-BCI: Forget-and-Adapt Deep EEG Decoding for Private Home Motor Rehabilitation
```

## Compile

Use Overleaf or run locally:

```bash
pdflatex main.tex

```

The references are embedded in `main.tex`, so BibTeX is not required.
